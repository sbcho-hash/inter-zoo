# 전시회 참관 가이드 v5

Interzoo 현장용 PWA입니다.

## 화면 구성

1. 참관 가이드
   - 참관 목적
   - 핵심 질문
   - 현장 체크리스트
   - 부스 A/B/C 우선순위
   - 패키지 디자인 체크리스트
   - OEM/ODM/PB 상담 체크리스트

2. 부스 기록
   - 브랜드/국가/부스번호/카테고리 기록
   - 사진 여러 장 첨부
   - 카메라 촬영
   - 녹음 메모
   - 점수화 및 우선순위 지정

3. 보고서
   - 보고 포함 또는 A등급 부스를 기준으로 자동 요약
   - TXT 저장
   - JSON 백업/복원

## GitHub Pages 업로드

압축을 풀고 폴더 안의 파일 전체를 기존 GitHub repository에 덮어쓰기 업로드하면 됩니다.
기존 현장노트 데이터를 자동으로 새 저장 키로 가져오도록 처리했습니다. 같은 GitHub Pages 주소에서 업데이트하면 기존 부스 기록을 이어서 사용할 수 있습니다.

## 설치

- iPhone: Safari로 접속 → 공유 버튼 → 홈 화면에 추가
- Galaxy/Android: Chrome으로 접속 → 설치 또는 홈 화면에 추가


## v6 변경사항
- 4번째 탭 `회화` 추가
- 부스 방문, 제품 문의, OEM/ODM/PB 상담, 자료 요청, 후속 연락용 영어 문장 추가
- 문장 검색 및 영어 문장 복사 기능 추가


- 회화 탭에 영어 듣기(Web Speech API) 기능 추가: 듣기 / 천천히 버튼 지원


## v8 추가 기능
- `통역` 탭 추가
- 한국어 → 영어 / English → Korean 방향 전환
- 음성 인식으로 문장 입력
- 전시회 상담용 문장 패턴 기반 번역 보조
- 번역 결과 크게 보기, 듣기, 복사 지원
- 음성 인식 미지원 브라우저를 위한 직접 입력 방식 유지


## v9 수정 내용
- 통역 탭을 여행 회화용 PWA와 유사하게 재구성
- 앱 내부 패턴 번역 대신 Google 번역으로 바로 넘기는 방식 적용
- 갤럭시: Chrome/Samsung Internet 음성 인식 지원 시 앱 버튼 사용
- 아이폰: 입력칸 + 키보드 마이크 받아쓰기 방식 안내 및 지원
- 상대방에게 보여줄 통역 요청 문장 추가


## v10 추가 기능
- 통역 탭을 앱 내부 번역 구조로 재구성
- Cloudflare Worker + DeepL API 연동 예시 포함
- 번역 Worker 주소를 앱에서 저장/테스트 가능
- Worker 미연결 시에도 빠른 문장/문장 보조 모드로 사용 가능
- 아이폰은 입력칸에서 키보드 마이크 받아쓰기, 갤럭시는 앱 내 말하기 우선 지원

### 중요
API 키는 PWA 파일에 넣지 말고 `translation-worker/deepl-worker.js`를 Cloudflare Worker로 배포한 뒤 Secret으로 저장하세요.
